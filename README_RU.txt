CREATORFORGE — ПУБЛИЧНЫЙ САЙТ ДЛЯ TIKTOK REVIEW
=================================================

Эта папка НЕ содержит основной код CreatorForge.
В ней только публичная информационная страница, Privacy Policy и Terms of Service.

ПЕРЕД ЗАГРУЗКОЙ НА GITHUB ОБЯЗАТЕЛЬНО:

1. Найдите строку CHANGE_ME_EMAIL во всех HTML-файлах.
2. Замените её на реальный email, по которому TikTok и пользователи смогут связаться с вами.
3. Сохраните файлы.

Файлы, которые можно публиковать:
- index.html
- privacy.html
- terms.html
- assets/styles.css
- assets/favicon.svg
- .nojekyll

Основной CreatorForge, .env, API keys, OAuth tokens, Docker-файлы и backend сюда НЕ копировать.

После публикации GitHub Pages ожидаемые ссылки будут:
https://ВАШ_GITHUB.github.io/ИМЯ_РЕПОЗИТОРИЯ/
https://ВАШ_GITHUB.github.io/ИМЯ_РЕПОЗИТОРИЯ/privacy.html
https://ВАШ_GITHUB.github.io/ИМЯ_РЕПОЗИТОРИЯ/terms.html

TikTok URL verification:
Когда TikTok выдаст signature file, скачайте его и положите в корень этого репозитория/сайта в ТОЧНОМ месте, которое потребует TikTok. Затем сделайте commit и подождите обновления GitHub Pages перед Verify.
